# ForMe World — план редизайна клиента

Рабочая ветка: `forme-ui-redesign-v2`  
Базовая ветка: `forme-ui-redesign-20261112`

## Направление

Визуальная система следует утверждённым концептам ForMe World: тёмная сливово-фиолетовая основа, мягкие неоновые акценты, стеклянные поверхности, тонкие контуры, скруглённые карточки и светлая типографика.

Редизайн выполняется поверх существующего Firestorm viewer. Нативные обработчики, авторизация, инвентарь, чаты, платежи и сетевые сценарии должны оставаться источниками поведения; визуальные поверхности меняются постепенно, без подмены рабочих функций статическими макетами.
