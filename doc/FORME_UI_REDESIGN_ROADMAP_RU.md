# ForMe World — план редизайна клиента

Рабочая ветка: `forme-ui-redesign-v2`  
Базовая ветка: `forme-ui-redesign-20261112`

## Направление

Визуальная система следует утверждённым концептам ForMe World: тёмная сливово-фиолетовая основа, мягкие неоновые акценты, стеклянные поверхности, тонкие контуры, скруглённые карточки и светлая типографика.

Редизайн выполняется поверх существующего Firestorm viewer. Нативные обработчики, авторизация, инвентарь, чаты, платежи и сетевые сценарии должны оставаться источниками поведения; визуальные поверхности меняются постепенно, без подмены рабочих функций статическими макетами.

## Границы текущего этапа

Текущий проход начал отдельную ForMe UI-архитектуру: новый workspace sidebar создаётся с нуля и подключается поверх существующего 3D world view. Старые механизмы инвентаря и карты пока только открываются через навигационные действия, их интерфейсы не переделывались. Нативный Home dashboard уже создан как стартовая поверхность с рабочими переходами; динамические карточки профиля, событий и аккаунта пока не подключены. GitHub Actions выполняет исходные UI/preflight проверки; полная сборка viewer и визуальная приёмка в запущенном клиенте остаются отдельными этапами.
