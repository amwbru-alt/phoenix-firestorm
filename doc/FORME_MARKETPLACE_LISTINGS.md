# Нативные листинги ForMe.World

Серверная первая версия: `amwbru-alt/SERVER`, ветка
`pr-56-review-fixes-20261013`, инструкция `doc/MarketplaceListings.md`.
Старый скачанный архив macOS этой интеграции ещё не содержит — нужен новый build.

Клиент использует штатное окно Marketplace Listings и JSON VMM через capability
`DirectDelivery` текущего региона закреплённого сервера. Меню, toolbar, окно и
контекстные действия доступны Владельцу/Дизайнеру после доверенных метаданных
аватара. Отсутствие capability или роли закрывает доступ; смена региона/роли
перезапускает проверку продавца. Ответы семи API-запросов из прежней capability
отбрасываются. Ссылки кабинета продавца направлены в собственный сайт.

На сервере отдельно проверяются роль, право продавца, владелец инвентаря и права
доставки. Клиентские проверки не заменяют серверные. Внешний браузер использует
обычный вход сайта: пароль viewer/сессионный токен не вставляются в URL.

Первая версия поддерживает создание черновиков, выбор версии, публикацию,
снятие, перепривязку и архивирование copyable товаров. Карточка/цена редактируются
на сайте перед публикацией. Конечный stock, No-Copy, миграция Merchant Outbox и
полная совместимость всех бизнес-правил Second Life пока не реализованы.

Локальные проверки: `python3 tests/forme/check_marketplace_listings.py`, общий
набор ForMe policy/badges/creator access. Приёмка требует новой полной сборки
клиента и проверки с обновлёнными Robust/симулятором, включая отзыв роли,
переход региона, покупку и доставку другому пользователю.
