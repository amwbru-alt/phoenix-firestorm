# Публикация товара ForMe.World

## Перед началом

Нужны бейдж owner (Владелец) или designer (Дизайнер) и включённый доступ продавца на сервере сайта. Бейдж сам по себе не заменяет доступ продавца. Настройки и назначения ролей на Robust и симуляторе должны совпадать.

Для первой проверки используйте собственный копируемый предмет с разрешением передачи. Нативные листинги пока не поддерживают передачу оригиналов No-Copy. Не проверяйте доставку единственным экземпляром ценной вещи.

## Из клиента: папка → черновик → карточка → публикация

1. Откройте «Продажа товаров…» в меню клиента.
2. В системной папке Marketplace Listings создайте отдельную папку товара, например «Стул». Внутри создайте папку версии «Версия 1», положите продаваемые предметы в неё. Не переносите в товар весь личный инвентарь.
3. Выберите папку товара. В контекстном меню Marketplace нажмите «Создать список». Это создаёт черновик, а не публичный товар.
4. Нажмите «Изменить список». Откроется наш сайт product-edit.html?item_id=vmm-ЧИСЛО. Войдите на сайт тем же аккаунтом.
5. Укажите название, категорию, цену, описание и фотографии. Сохраните. Идентификатор vmm-… и источник доставки сохраняйте: ими управляет клиент. Не создавайте вместо этого вторую карточку через «Добавить товар».
6. В клиенте выберите нужную версию, проверьте товар через «Проверка на ошибки», затем нажмите «Опубликовать». Карточка сайта должна быть сохранена до публикации.
7. Проверьте каталог из другого аккаунта. Для теста доставки используйте отдельного покупателя и недорогой тестовый товар.
8. Для временного скрытия используйте «Отменить публикацию» в клиенте. Не удаляйте товарные папки из инвентаря, пока товар продаётся.

Структура папок:

- Marketplace Listings (системная папка)
  - Стул (папка объявления)
    - Версия 1 (папка поставки)
      - Стул (предмет)
      - Инструкция (при необходимости)

## Альтернативно: создание на сайте

Это отдельный способ публикации. Создайте в инвентаре папку SELLFORME и поместите внутрь отдельную папку товара с продаваемым содержимым. На сайте откройте кабинет продавца → добавление товара → «Открыть папку SELLFORME», выберите папку товара как источник доставки, заполните карточку и сохраните.

Если используется ручной источник, нужен UUID предмета инвентаря или папки, а не Asset UUID и не UUID объекта, стоящего в регионе. Выбирайте один вариант: папка либо отдельные предметы. Не смешивайте этот способ с уже созданным vmm-листингом.

## Ошибка «Unknown error»

Это общее сообщение клиента, по которому нельзя определить причину отказа. Приведённые строки LLUDPSERVER о повторно полученных AgentAnimation и RequestObjectPropertiesFamily не содержат ответа API маркета.

Для диагностики нужны строки журнала клиента с «SLM API», HTTP-кодом и описанием ответа, а также сообщения Robust «WEB PORTAL» и симулятора около того же времени. Не публикуйте полные конфиги, токены, пароли и capability URL.

Проверьте MarketplaceViewerListingsEnabled на Robust, MarketplaceListings.Enabled на симуляторе, правильный ServiceURL, совпадение общего секрета, назначение бейджа и разрешение продавца. Не отключайте проверку подписи ради устранения ошибки.

Связанные серверные настройки описаны в SERVER/doc/MarketplaceListings.md.
